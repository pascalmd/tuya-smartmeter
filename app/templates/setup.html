Wie komme ich an Access ID und Secret? (nur für den Fall, dass du sie brauchst)

iot.tuya.com ist ein eigenes Konto, getrennt von der Smart-Life-App — dein App-Login funktioniert dort nicht. Deine Geräte musst du deswegen trotzdem nicht neu einrichten. Und der ganze Weg ist nur nötig, wenn die QR-Anmeldung bei dir nicht funktioniert.

  1. Auf iot.tuya.com registrieren (kostenlos).
  2. Links Cloud → Development → Create Cloud Project. Data Center: Central Europe.
  3. Beim Anlegen die APIs IoT Core, Authorization und Smart Home Scene Linkage auswählen.
  4. Im Projekt unter Overview stehen Access ID und Access Secret — die beiden hier eintragen.
  5. Im Reiter Devices → Link App Account per QR-Code das Smart-Life-/Tuya-App-Konto verknüpfen. Erst dann sieht dieses Programm den Zähler.

Hinweis: Tuya befristet neue Projekte auf einen Testzeitraum. Läuft er ab, lässt er sich unter Service API → IoT Core → View Details mit Extend Trial Period kostenlos verlängern — das ist ein Antrag, den Tuya prüft, kein Klick.
