Tuya-Cloud

Wichtig: Hier gehören nicht E-Mail und Passwort der Smart-Life-App hin. Tuya erlaubt fremden Programmen den Zugriff nur über ein kostenloses Entwickler-Projekt. Die Anleitung dafür steht unten.

Wie komme ich an Access ID und Secret?

  1. Auf iot.tuya.com registrieren (kostenlos).
  2. Links Cloud → Development → Create Cloud Project. Data Center: Central Europe.
  3. Beim Anlegen die APIs IoT Core, Authorization und Smart Home Scene Linkage auswählen.
  4. Im Projekt unter Overview stehen Access ID und Access Secret — die beiden hier eintragen.
  5. Im Reiter Devices → Link App Account per QR-Code das Smart-Life-/Tuya-App-Konto verknüpfen. Erst dann sieht dieses Programm den Zähler.

Hinweis: Tuya befristet neue Projekte auf einen Testzeitraum. Läuft er ab, lässt er sich im Projekt unter „Service → Extend Trial" kostenlos verlängern.
